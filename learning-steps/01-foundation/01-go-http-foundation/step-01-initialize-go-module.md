# Step 1 — Inisialisasi Go module

Jalankan:

```bash
cd /Users/mac/Documents/bbge/practice
mkdir srv-server
cd srv-server

go mod init github.com/imamsyafii-dev/bbge-practice/srv-server
```

Hasil yang diharapkan:

```text
go: creating new go.mod: module github.com/imamsyafii-dev/bbge-practice/srv-server
```

Belum perlu menjalankan `go mod tidy` karena belum ada package Go.
